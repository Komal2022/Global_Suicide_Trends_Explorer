## 📌 Overview

The **Global Suicide Trends Explorer** is a data-driven project aimed at analyzing and visualizing suicide trends across different countries, age groups, and time periods.
This project focuses on extracting meaningful insights from global data to support awareness, research, and informed decision-making in the mental health domain.

---

## ❗ Problem Statement

Mental health issues, including suicide, are a growing global concern. However, understanding patterns across countries, age groups, and time is challenging without proper data analysis.

This project aims to bridge that gap using data-driven insights.

---

## 🎯 Objectives

* Analyze global suicide data over multiple years
* Identify patterns based on **age groups, gender, and countries**
* Perform exploratory data analysis (EDA)
* Visualize trends using graphs and dashboards
* Highlight critical insights for awareness and research

---

## 📂 Dataset

* `master.csv` – Raw dataset containing global suicide statistics
* `cleaned_suicide_data.csv` – Preprocessed dataset after cleaning and transformation

## 🚀 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Global_Suicide_Trends_Explorer.git
```

2. Navigate to the project directory:

```bash
cd Global_Suicide_Trends_Explorer
```

3. Install dependencies:

```bash
pip install pandas numpy matplotlib seaborn streamlit
```

4. Run the application:

```bash
streamlit run app.py
```

## 📌 Key Insights

* Countries show **significant variation** in suicide rates
* **Middle-aged and elderly populations** are more vulnerable
* Male suicide rates are generally **higher than female rates**
* Trends indicate **fluctuations based on social and economic factors**
